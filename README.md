# BikeHub – Bike Service Management System

##  Overview

BikeHub is a full-stack web application developed using Django to streamline and automate bike service center operations. The system enables efficient management of service requests, mechanic workflows, and spare parts ordering, providing a seamless experience for both customers and administrators.

---

##  Key Features

* **Service Booking System** – Customers can book bike services and track their status
* **Mechanic Dashboard** – Manage assigned services and upload work updates
* **Work Progress Tracking** – Real-time updates with service-related information
* **Spare Parts E-commerce Module** – Browse, select, and order spare parts
* **OTP-Based Order Verification** – Secure checkout process
* **Admin Controls** – Manage operations including service flow and labor charges
* **Attendance Management** – Monthly attendance tracking for mechanics

---
